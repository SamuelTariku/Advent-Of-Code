# Advent of Code Solutions

![Advent of Code](images/santa.png)

My solutions to [Advent of Code](https://adventofcode.com/), an annual collection of programming puzzles created by [Eric Wastl](https://was.tl/).

## Structure

```text
AdventOfCode/
└── 2025/
    ├── day1/
    ├── day2/
    ├── day3/
    └── ...
```

Each year contains a directory for every day, with separate solutions for each puzzle part. Test cases and other supporting files are kept alongside their respective solutions.
